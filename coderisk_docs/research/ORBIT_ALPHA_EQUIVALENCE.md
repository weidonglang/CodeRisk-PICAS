# S1 群作用、轨道、商集与 α-等价

状态：**条件证明 + 自有有限测试**。不是完整 Java/Python 正确性证明或语义等价判定。定义服务于可检验的规范化契约，不宣称首次应用群论。

## 1. 对象及固定域

固定语言 L、非名称语法骨架、词法绑定图 B、可移动 ASCII 拼写域 N、受保护名称 F，且 N∩F=∅。N 有限，含未使用名称；不含关键字、内置/导入/API/动态查询名称、入口/文件名及未解析自由名称。F 至少覆盖程序及契约中所有不允许重命名的名称。字符串/注释不是可移动名称出现，保持原字面量；存在字符串查名等运行时依赖时，不满足前提。

一个声明节点 b 是**绑定身份**，不是字符串。引用位置 o 具有 binding(o)=b；直接内部调用 keyword label 只有在 callee 唯一且签名已解析时才作为参数绑定出现。两个作用域的同名声明可以是不同 b，却共享同一个拼写。

程序域 ℙ 不等于“实现 mode 为 scope-aware 的所有输入”。它是满足支持语法、绑定已正确识别、外部名保护、无动态名字依赖，并对下面所有置换封闭的程序集合。可以先在固定骨架、B 和名称相等关系下生成一个轨道；再取这些轨道的并。若只逐输入删去非法变体却仍叫整个 Sym(N) 的作用，封闭性不足，需要缩小对象域或明确合适子群，不能略过。

## 2. G、作用及群公理

G=Sym(N)，函数复合为群运算，将 g 扩展为 F 上恒等。`g·P` 对 N 中所有已经确认的绑定声明/引用/内部参数标签，统一同时应用 g；同一拼写的不同绑定一起移动。非名称 token 不变。生成工具先按 token 位置收集替换，再从后向前写入，不用串行文本 replace，避免把 x→y 后再 y→z 误作同时置换。

**条件引理 A（群作用）**：在上述封闭对象域上，e·P=P，h·(g·P)=(h∘g)·P，g⁻¹·(g·P)=P。

证明：在任一可移动位置名 n 上，恒等给出 n，复合给出 h(g(n))，逆给出 n；所有其他位置固定，语法骨架不变，因此逐 token 相同。源码列宽可变，但 token 顺序及绑定位置的结构对应不变。双射保持名称相等/不等，N∩F=∅ 防止撞入固定符号；词法解析与支持域封闭为前提。任意 x→y、y→y 不是双射，不能使用该引理。

## 3. 轨道、等价关系与商集

定义 `[P]G={g·P:g∈G}`，`P ~G Q ⇔ ∃g∈G, Q=g·P`。由 e 得反身，由逆得对称，由复合得传递；因此是真正等价关系。`ℙ/G` 是全部轨道组成的商集，不是分数区间、风险等级或教师处分类别。

`Stab(P)={g:g·P=P}` 是稳定子。固定有限 N 时 `|[P]G|=|G|/|Stab(P)|`。在本轮金样例中 k 个 N 名称真的出现，其余不出现、外部固定，则稳定子可任意置换未使用名，轨道大小为 `|N|!/(|N|-k)!`。144 次抽样置换包含多 seed 重复、恒等和稳定子效应，不意味着 144 个不同程序，更不是 144 名独立作者。`fixture_summary.csv` 逐项列唯一置换和唯一源码 hash。

## 4. C 的条件不变性与商集下降

C(P) 是 `CanonicalAnalysis.tokens` 的**完整有序**序列。对每个内部绑定生成“结构作用域路径::角色序号”，每个引用用该绑定的序号；非内部 token 保留。它不是合法源码 P 的某个代表元，也不是选择字典序最小变体的轨道 canonical representative；更准确称为“轨道常值特征”。

**条件命题 B**：若 D1：绑定图正确且在 g 下同构；D2：作用域路径、角色、声明遍历次序与 raw 名无关；D3：全部选定声明/引用/可解析标签覆盖正确、固定 token 保留，则 `C(g·P)=C(P)`。

证明：按词法作用域树深度及各作用域声明次序归纳。根作用域路径固定；对应第 j 个角色声明的角色编号相同。对子作用域，其位置及创建次序不变，路径相同。由 D1，引用和标签指向对应声明；由 D3，它们写入相同规范 token。其余 token 相同，故有序序列逐项相同。名称长短导致列变化不影响结构顺序；源码行列元数据本身不要求相等。

推论：`P ~G Q ⇒ C(P)=C(Q)`，且存在唯一函数 `C̄:ℙ/G→Seq(Token)` 满足 `C=C̄∘π`，其中 π(P)=[P]G。良定义性来自轨道内常值，唯一性来自 π 满射。**没有得到 C̄ 单射**；也没有得到 converse、语义正确、分数不变或抄袭判定。

这是关于满足 D1—D3 的规范化算子的条件证明，不是将“索引器正确”偷偷证明了。Python 原生 AST 可识别语法，但绑定/keyword 与类定义期仍需正确实现；Java brace 近似没有完整名称/类型解析。本轮有限独立 golden 提高证据，不完成全语言证明。

## 5. 为什么不能把 G 轨道等同于 α-等价

α-等价通常固定自由名字、按**绑定身份**进行捕获规避改名，保留引用关系。本项目使用这个思想处理限定程序的词法绑定；不是把整个现实 Java/Python 程序直接解释成 λ 项。全局内部函数/类/公开属性还涉及外部接口，必须先声明保护边界。

在每个可移动名都确属内部绑定且外部固定等前提下，统一 G 置换是一种捕获规避改名，因此 G 轨道关系蕴含这个受限绑定 α-关系。反向不成立：

```python
# P：两个不同绑定共享 value 拼写
def fold(value):
    return value + 1
def process(value):
    return value + 2

# Q：分别局部改名
def fold(left):
    return left + 1
def process(right):
    return right + 2
```

两者绑定骨架相同、局部改名合法，本轮 C 相同。但不存在单值 g 同时令 g(value)=left 与 g(value)=right，故不在同一统一拼写轨道。对该反例，C̄ 非单射：不同 G 轨道可能映射为同一 C。并非算法犯错，也不是“改名不变因此不会误报”的理由。

捕获反例：`def f(x,y): return x+y` 单独 x→y 得到重复参数/捕获，不是 α-等价，也不是 G 中双射。`globals()['x']`、外部调用参数、Java 重载/接口名字不能在无约束时作为普通绑定移动。

## 6. 表示相等、指纹相等及判别能力

表示稳定性与判别力是不同问题。本轮两个程序分别执行两次/三次 `total=total+1`，C 不同，却有相同 canonical n-gram 集合；raw、基础 AST、mapping 和当前融合分也均为 1。集合表示丢失次数，不是语义等价证明。本轮只用自有简单整数机制观察，不对真实学生标签计算 FPR。

`C相等 ⇒ canonical集合相等`；逆一般不成立。raw 成分会随合法改名改变，因此不声称 PICAS weighted score 属于群不变量。风险阈值是否改善真实误报，是另一项必须有独立标签/数据的统计研究。

## 7. 与既有理论的关系

[de Bruijn 原始稿](https://automath.win.tue.nl/archive/pdf/aut029.pdf)讨论以无名绑定表示处理名称差异；本项目使用作用域路径/角色次序，**不是 de Bruijn index 的实现或其完整定理应用**。已读取引言及相关方法节选，不猜未核实 DOI。

[Gabbay/Pitts 机构题录](https://researchportal.hw.ac.uk/en/publications/a-new-approach-to-abstract-syntax-with-variable-binding/)与[作者 PDF](https://www.gabbay.org.uk/papers/newaas-jv.pdf)为变量绑定/nominal 背景；题录已核实，PDF 文本提取乱码，不能标作全文已读。[Pitts 作者 Lecture 1](https://www.cl.cam.ac.uk/teaching/1314/L23/lectures/lecture-1.pdf)已查阅 swapping、α-等价与商对象部分；书籍只核查题录，未阅读全文。Nominal 理论常用无限原子集及有限支撑置换；本轮选择固定有限 N，是工程验证模型，不等同于完整 nominal framework。

出处与实际阅读范围见 [文献矩阵](../proposal/LITERATURE_MATRIX.md)。本章命题是项目限定条件下的推导，来源只提供理论背景，不替本项目证明 Java/Python 绑定正确。
