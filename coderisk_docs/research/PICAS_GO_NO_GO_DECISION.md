## 分模块决定与可反驳条件

| 模块/论断 | 当前建议 | 改变决定需要什么 |
| --- | --- | --- |
| 受限群作用规范化与独立验证 | 保留方法研究 | 受支持语法出现绑定/不变性反例须修正；真实NoCanon/JPlag无净收益就不宣称检测优势 |
| 规则动态阈值 | 冻结生产，暂缓继续调系数 | 新冻结可信cohort中FPR/Recall代价可接受；不可在已见test优化 |
| 统计q/新融合或LLM增强 | 暂停追加研发预算，保留旧隔离工具/历史 | 有可信参考、完整标签、成本/可靠性基线后再判断，不因参考0直接称方法无效 |
| 题目预检/只读证据卡 | 小范围走查候选，不上线 | 相对JPlag/原报告确有可核查新信息；若无益/误导就STOP FEATURE |
| AI概率、个体模型归因、自动违规结论 | STOP FEATURE，不开发 | 不由当前源码管线解决；即使有过程资料也需另有合法人工程序，不能用本项目绕过 |
| 大型Dashboard/更多算法/规模凑数 | 停止本阶段扩张 | 不服务当前可证伪价值问题，不以代码行数或未标注规模证明贡献 |

## 正式GO最低条件

有授权、可追溯真实会话/独立与父版本依据、两位真人及冲突处理、配置和problem/source/session/hash冻结；在未用来调参的新test上以共同支持与合理基线重复比较。至少一个预定义场景存在可解释净价值，且不能掩盖另一端Recall/FPR、成本或隐私恶化。若结论不显著/不可估计，保留N/A/INSUFFICIENT，不能“趋势看上去好”升级GO。

检测无收益但性质分析严谨可以PIVOT；若只读卡未增益则不集成；真正停止个体AI归因不等于放弃整个毕设。当前**没有发现可被称为正式增益的证据**，也没有资格根据mock分布证明整个项目毫无用处。

最高价值只留三个待办：①许可/冻结的4—8题真实小试点；②同cohort Raw/NoCanon/PICAS/JPlag比较及失败机制；③有同意的教师盲走查决定卡是否保留。更多开发暂后置。
