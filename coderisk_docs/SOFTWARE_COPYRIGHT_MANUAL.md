## 1. 软件基本信息

### 1.1 软件名称

推荐名称：

```text
CodeRisk 题目复杂度自适应代码相似风险检测系统
```

中文全称：

```text
基于题目复杂度自适应与置换不变结构表示的代码相似风险检测系统
```

简称：

```text
CodeRisk / PICAS
```

### 1.2 软件版本

```text
V1.0
```

### 1.3 软件类型

```text
应用软件 / 教育辅助软件 / 代码相似度检测与风险分析系统
```

### 1.4 软件用途

本软件面向高校程序设计课程、算法训练、课程设计和实验作业场景，提供题目创建、代码上传、代码相似度检测、题目复杂度自适应阈值计算、相似风险等级评估、结构化证据展示和报告导出等功能。

软件不直接判定抄袭，而是输出相似风险等级、动态阈值、多维相似度指标和证据片段，辅助教师或管理员进行人工复核。

## 8. 主要算法说明

### 8.1 代码预处理

系统对原始代码进行注释清理、编码规范化、空白处理和语言识别。

### 8.2 置换不变规范化

系统对变量名、函数名和参数名进行归一化处理，以降低命名替换对检测结果的影响。

### 8.3 题目复杂度评分

系统根据题目描述、输入输出格式、约束条件和参考答案计算题目难度、解法空间、模板风险和自然相似风险。

### 8.4 动态阈值计算

系统根据题目画像动态调整相似风险阈值。简单题和模板题提高阈值，复杂题和解法空间大的题目降低阈值或提高结构证据权重。

### 8.5 多维相似度融合

系统融合 token、AST、控制流、数据依赖、操作序列、稀有片段和跨语言 IR 相似度，生成综合风险分数。

## 11. 异常处理说明

### 11.1 文件上传失败

可能原因：

```text
文件格式不支持
文件大小超过限制
网络中断
编码异常
```

处理方式：系统提示错误原因，用户重新上传。

### 11.2 代码解析失败

可能原因：

```text
代码语法错误
语言识别错误
解析器不支持特定语法
文件内容不完整
```

处理方式：系统保留原始代码，并降级使用 token 或文本特征进行基础检测。

### 11.3 算法服务不可用

处理方式：系统提示算法服务异常，并允许用户稍后重试；已保存的任务不丢失。

### 11.4 报告导出失败

处理方式：系统保留检测结果，用户可重新触发导出。
