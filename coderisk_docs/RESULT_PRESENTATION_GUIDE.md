# 结果展示与图表阅读

更新：2026-10-16。本轮是前端展示增强，不更换生产评分公式、风险分类、API 或数据库结构。图表只读取原 API 数字；没有引入图表依赖或模型调用。

## 从任务到证据

1. 在检测任务中进入结果页，先核对任务状态、成功覆盖率、失败/恢复记录。未完成任务的分布和报告只是已成功部分。
2. 风险分布来自后端全任务 summary，包含低、中、较高、高四类。当前页的搜索、筛选、分页不会改变全任务分布。
3. 列表保留所有分量；图表仅对当前页筛选后的代码对进行综合分/阈值对比，不声称展示了全任务所有点。
4. 点击代码对进入详情，比较综合分、题目阈值、风险边际与原分量，再查看原文证据、题目画像、共同模板和声明版本。
5. 证据类型可以筛选。定位按钮和手机证据项会跳转源码，并将长代码滚动到对应行。无行号的复核说明不伪造高亮。
6. 源码支持并排/上下、自动换行和复制；规范化映射可搜索 A/B 名称、规范名及作用域。
7. 任务页可导出 HTML；详情页“任务报告”导出的是所属任务全部成功结果，而不是只有当前代码对。

## 图表语义

| 展示 | 数据和含义 | 不能推论 |
| --- | --- | --- |
| 风险分布 | 全任务已生成结果的原后端等级计数；零结果保持空态，不做除零 | 比例不是同学作弊率，也不是正式实验 FPR |
| 分数与阈值 | 绿色点为原综合分，虚线为原阈值；共同0–100%刻度；数字保留1位小数 | 不是概率；图表不重算风险分类或改变排序 |
| 风险边际 | API 的 riskMargin，以百分点 pp 显示，保留正负号 | 不将分量或差值额外加入生产总分 |
| 四维分量 | Raw Token、基础AST、Canonical Token、Identifier Mapping 原值 | 不支持项保持“-”和缺失纹理，不能当作0分 |
| Canonical − Raw | 两个有效分量之差，以pp显示；任何一项缺失就不计算 | 不是规范化识别成功率、改名关系证明或风险额外加分 |
| 阈值分解 | 原基础值、难度/空间/模板/自然相似/历史分布调整及最终值；正负条以0为中心、每个详情共用尺度 | 缺失项不补0；最终值来自API，不用图形累计推断，避免忽略裁剪边界 |

图表同时保留数字和可访问标签，不依赖颜色单独传意。HTML有限分支继续标记固定阈值待验证；experimental IR/轻量摘要仍在单独标签页，生产权重0，不因为有图形就升级为稳定能力。

## 仍需注意

结果和题目搜索仍是当前页，任务搜索仍是最近任务。没有新增全库搜索、全任务散点采样或复杂Dashboard。前端旧依赖的PURE/大chunk警告保留，不通过隐藏警告冒充性能优化。

“calibratedRiskScore”是现生产规则中的边际展示映射，非已经过真实独立样本验证的概率校准。界面改善不能证明动态阈值降低真实误报，不能识别AI来源，也不能认定学术违规。下载数据量、自动化测试数与可信标注样本数是不同口径。
