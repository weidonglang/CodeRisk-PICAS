## 2. 候选与首批盲审

候选共 1,174 对：AD2022 249 对、ConPlag 911 对、CodeNet C 同题候选 10 对、MDN 同模块候选 4 对。候选的关系仍为 `UNCERTAIN`，不将同题、高相似或不同编号当成正负例。

首批 43 对包含 Java 27、Python 6、C 6、HTML 4。ConPlag 每个公开题目选一对，其他来源按语言选取少量样本。选择顺序使用稳定 ID 哈希，不依据检测分数或公开标签。

本机离线入口：`coderisk/data/public-datasets/review-workbench-20261009-v2/review.html`。双击后即可使用，源码仅作为文本呈现。该文件含原始代码，位于 Git 忽略目录中；不要提交到仓库。工作台不显示公开标签或检测分数，另外保存的公开标签参考文件只能在初始独立复核完成后打开。

两位真实复核者分别使用各自的页面会话：填写匿名 ID，逐对检查来源与功能证据，选择标签并写具体依据，保存后导出 JSON。第一次保存会锁定复核者 ID。保存仅在页面内存中，刷新和关闭会丢失，离开前必须导出；导出后可将文件重命名为 `reviewer-a.json`、`reviewer-b.json`。不得由同一人用两个 ID 代替独立复核。

标签含义沿用 [数据与标注规范](DATA_PROTOCOL.md)：明确派生用 `TRANSFORMED`，有记录的复制/重复版本用 `SIMILAR`，有独立创作依据用 `INDEPENDENT`，同时存在模板或题目约束的独立创作用 `NATURAL_SIMILAR`，证据不足用 `UNCERTAIN`。MDN 教学示例默认不能视为独立学生解答；CodeNet 同题提交也无法仅凭源码确认独立关系。

在仓库根目录合并两人的导出：

```powershell
python coderisk/experiment/prepare_annotation_workbench.py --merge reviewer-a.json reviewer-b.json --manifest coderisk/data/public-datasets/review-workbench-20261009-v2/first_batch_manifest.jsonl --output coderisk/data/public-datasets/merged-review-01
```

合并器校验队列哈希、源码哈希、不同复核者 ID、合法标签、具体依据和带时区的日期。同意为 `AGREED`，分歧为 `DISAGREED`，缺失或不完整为 `INCOMPLETE`；未达成一致仍为 `UNCERTAIN`。合并不会自动设置正式指标资格，仍须核验来源/功能证据、冻结划分和研究方案。这里的“同意”是文件记录状态，不能据此证明两人确实独立完成。

## 3. 防泄漏划分的现实限制

新队列按同题、已知提交/作者家族、所有已知视图的文本哈希构建传递连通组，AD2022 还暂按去掉语言后缀的相同题名归组。题名只是保守初筛，题意相近但题名不同仍须人工补充归组。

| 来源 | 候选对 | 连通组 | 验证/测试提案 |
| --- | ---: | ---: | --- |
| AD2022 | 249 | 2 | 132 / 117 |
| ConPlag | 911 | 21 | 218 / 693 |
| CodeNet C | 10 | 10 | 3 / 7 |
| MDN HTML | 4 | 4 | 1 / 3 |

这些是 seed=20261009 的未冻结提案，不表示具有统计代表性的测试数据。AD2022 仅两组，不适合进行可靠的组间泛化统计；C/HTML 数量小且无标签。未知作者不能被当作不同作者。应继续获取新的可追溯题目和独立解答，而不是随机拆开已有相连样本凑测试集。

ConPlag 公开标签探索实验另行沿用早先 seed=20261008 的 284/627 划分，已经在取得本次分数前单独冻结并上传；不可用本表替换。方案见 [运行前记录](../../coderisk/experiment/evidence/conplag-registration-20261009/README.md)。该数据缺少可靠题目画像与自然相似标签，只支持固定阈值/规范化/JPlag 的公开标签探索，尚不能检验毕设 RQ1。
