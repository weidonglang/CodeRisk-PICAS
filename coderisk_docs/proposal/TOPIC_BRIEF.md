# CodeRisk 本科毕业设计选题说明

## 建议题目

**基于题目感知与标识符规范化的编程作业代码相似风险检测系统设计与实现**

备选简化题目：面向编程作业的代码相似风险检测系统设计与实现。

第一个题目能够突出具体方法，第二个题目适合学校要求题名简洁的情况。题目不使用“语义等价”“抄袭判定”或“AI 生成识别”，避免超出当前能力。

## 选题对象与问题

研究对象是同一道编程题下的 Java 或 Python 同语言提交。系统比较代码的词法与基础结构信号，并提供题目画像、动态阈值、风险边际和复核证据。

代码相似与学术违规不是同一概念。对于共同模板、固定输入输出和集中解法产生的相似性，需要结合题目条件解释。Dolos 官方文档也明确提供模板文件排除机制，说明共同代码需要单独处理；但这一事实不能推出当前题目画像公式必然有效。[Dolos 模板处理说明](https://dolos.ugent.be/docs/running.html)

本课题拟验证：在既有代码相似度之上引入题目画像阈值，是否有助于控制自然相似误报；作用域标识符规范化是否能增强对改名的鲁棒性；结果和证据能否保持一致并追溯到源代码。

## 本科主线与个人工作

主线由四部分组成：标识符规范化、题目画像与阈值、相似度融合、结构化证据。后续个人工作重点为文献比较、真实数据建设、公平实验、失败分析及影响核心方法的缺陷修复。

作用域规范化是已有技术方向，不把使用规范化本身称为首创。题目感知与证据集成可以作为本系统的设计特色，其研究贡献由对比实验决定，不能仅凭方法名称判断。

## 与现有工具的关系

JPlag、Dolos 已提供成熟的代码相似分析与展示能力，不能笼统声称现有工具没有结构分析、规范化或可视化。本项目选择较小的编程作业场景，研究题目画像与风险阈值的关系，并整合可复核输出。其优势和代价需要在共同样本上验证。[JPlag 官方仓库](https://github.com/ls1intum/jplag)，[Dolos 论文](https://biblio.ugent.be/publication/8744589)

## 可直接用于向导师说明的段落

本课题拟设计并完善面向编程作业的代码相似风险检测系统，重点研究题目画像驱动的阈值调整和作用域标识符规范化。在已有系统原型基础上，构建可追溯的独立解答及改写样本，比较固定阈值与动态阈值、原始 Token 与规范化 Token，并开展指标消融和失败案例分析。系统面向 Java/Python 同语言代码对输出风险等级和复核证据，不直接认定抄袭。当前已具备基础实现与实验工具链，后续重点是可信数据与效果验证。

## 待导师确认的事项

- 题目是否采用突出方法的长题名，或采用简化题名。
- 毕设更侧重系统设计还是方法实验，以便分配论文章节篇幅。
- 是否能够获得经授权、已脱敏的编程作业或独立解答。
- 是否要求 MySQL 演示、指定基线、中文文献数量或特定材料格式。

没有这些信息仍可继续文献与实验方案准备，但不代替导师作出学校层面的审批决定。
