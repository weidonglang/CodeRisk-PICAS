## 3. 从原始文件发现的问题

以下为本轮文件统计，不是相似度检测结果。

### AD2022

- 各学期解答数541、415、570，与官方统计一致；对应CSV中实际出现的学生匿名ID数为83、89、127。这里统计的是已发布解答中的ID，不能直接替代官网的课程学生数。
- “同一题目、同一学生ID”有3条额外重复记录，分别在后两学期出现2条、1条。按原始行编号保存全部解答，不覆盖旧记录。
- 1,526份解答共有1,462个不同原始代码哈希，不能把每份文件视为完全独立的样本。
- 10个匿名ID出现在多个学期中。来源族保守地关联相同ID；跨学期同主题题目仍需人工关联，不能按学期直接随机分集。
- Java解答包含方法或片段，未来需要结合原始skeleton适配解析、编译与测试。当前保留原文，没有自动包装成完整类并冒充原始提交。

已生成249个同题、同语言待标注代码对：按CSV顺序取每题前四个不同学生ID，最多形成六对。此规则不使用检测分数，也不构成代表性随机抽样。所有候选标签均为 `UNCERTAIN`；不同学生ID、功能正确、代码不相同都不能证明独立完成。

### ConPlag

- 原发布的训练/测试表没有表头，必须保留首行；核验为230对训练、681对测试，覆盖全部911对，代码对ID无交集。
- 按本项目的隔离标准，两集共享21个题目、199个提交ID和192个原始代码哈希。原划分不适合直接用于声称跨题泛化的实验。
- 10个提交ID在不同代码对目录下有不同原始字节内容，统一换行后仍有差异。按代码对保存文件，并将同一提交ID关联到一个来源族；不以ID直接去重覆盖。
- 原始版、去模板版逐文件保留，记录两类版本的字节哈希和文本哈希。去模板版是同一标签对的配对视图，后续应按配对统计分析。
- 原发布标签完整保留在 `published_verdict`：1表示发布方正例，0表示发布方负例。这不等于已证明复制链，也不等于本项目已经双人复核。

已调用现有来源隔离工具生成一个**未预注册、待审查的划分草案**：21个关联组，284对拟作validation、627对拟作test。分组连接题目编号、提交ID和代码文本哈希，固定seed为20261008。草案尚未成为正式实验分集；没有按测试效果挑选划分。

## 4. 当前状态与后续使用

新数据以独立intake格式保存，没有填造题目难度、题型、变换等级、审阅者、功能验证或预注册记录；没有混入91对合成seed。`eligible_for_core_metrics=false` 表示尚未满足**项目当前正式评测协议**，并不表示公开数据没有价值。

可采取两条明确的后续路线：

1. **ConPlag外部基准**：单独固定使用公开标签的协议，明确单标注与选择偏差，审查分集后冻结。先评测raw/canonical/JPlag；没有真实题目画像时，不伪造动态阈值输入。报告与课程场景结果分开。
2. **AD2022课程实验**：先关联跨学期题目与来源族，选定题目画像规则，再补充可追溯正例和可信负例、双人复核及隔离的功能验证。249对候选只是标注准备池，后续抽样须单独设计。

本轮未运行下载代码、测试器或压缩包附带工具，也未计算相似度、Precision、Recall或F1。取得真实来源是已完成的进展；标签适用性、独立测试集和最终实验结论仍需要后续工作。

## 5. 重建与校验

获取脚本仅使用Python标准库，支持Python3.11+。以下命令从仓库根目录运行；输出必须使用不存在的新目录。

```powershell
python coderisk/experiment/acquire_public_datasets.py `
  --output coderisk/data/public-datasets/public-intake-rebuild

# 已有本地缓存时完全离线导入
python coderisk/experiment/acquire_public_datasets.py --offline `
  --output coderisk/data/public-datasets/public-intake-offline

# 对已完成的目录检查每个登记文件的大小与SHA256
python coderisk/experiment/acquire_public_datasets.py --verify-only `
  --output coderisk/data/public-datasets/public-intake-20261008
```

脚本只读取指定的数据成员，不执行下载内容。文件变化或校验不一致时失败，不自动替换固定校验值。输出中 `file_inventory.json` 登记数据与来源文件，不包含它自己及最后写入的摘要；GitHub证据包另记录这些文件的哈希。

本机Windows Store Python入口本轮无法启动，实际使用Codex依赖包中的Python3.12完成导入和标准库测试。此环境情况不改变数据内容。

八项导入回归测试覆盖：无表头分集首行、重复分集、原始变体保留、公开标签不自动晋升、未知分集引用、异常路径、CSV大字段与换行、课程重复记录、压缩包校验及导入文件变更。

证据入口：[`public-intake-20261008/README.md`](../../coderisk/experiment/evidence/public-intake-20261008/README.md)。
