# Research V4 Samples

Place new code files under one of these source-type folders:

```text
manual/          traceable human-created or human-rewritten samples
ai_assisted/     AI-assisted rewrites with full provenance and verification
external/        public or authorized external samples
synthetic/       extra synthetic workflow probes, never real benchmark evidence
placeholders/    incomplete placeholders, excluded from core metrics
seed/            deterministic synthetic seed generated by the project
```

Every path referenced by `pairs/manual_pairs.json` must stay below this `samples/` directory. Use `experiment/add_research_v4_case.py` to compute hashes and build manifest entries.

Do not move or rewrite `seed/` files to make them look like manual, external, or verified AI-assisted data.
