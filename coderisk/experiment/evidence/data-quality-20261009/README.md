# 公开数据质量复核

本次只进行来源哈希验证、语法检查、重复代码登记和分集提案，不运行下载代码，不产生关系标签或检测分数。

`quality_summary.json` 记录 3,865 条逻辑源码版本，按语言和字节内容去重为 3,647 份。ConPlag 的两个发布视图、同编号不同版本继续分别登记，不表示新增学生或独立样本。原始文件存放在忽略目录中。

- `source_quality_registry.jsonl`：来源、视图、题目、已知家族、字节和文本哈希、解析状态、功能证据未知项。
- `exact_text_duplicate_groups.json`：180 组精确文本重复，其中两组跨题目，零组跨数据集；不从重复推断关系标签。
- `language_or_syntax_review_queue.jsonl`：待核验的解析失败、C++ 语法信号和旧 Python 语法信号。
- `split_proposals.json`：新标注候选队列的保守分组提案，seed=20261009。AD2022 因已知学生家族、题目和文本联系形成两个连通组，不适合据此宣称稳健的独立测试。

新标注提案中 ConPlag 为 218/693 对；运行前冻结的公开标签探索实验沿用原接收提案 284/627 对。两者用途不同，不能替换冻结的实验划分。

质量登记不代表代码正确：Java 使用现有简化结构解析，Python 使用当前解释器 AST，C/HTML 使用指定 Tree-sitter 语法；全部未作编译、判题或作者身份核验。
