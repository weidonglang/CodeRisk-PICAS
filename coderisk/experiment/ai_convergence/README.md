# Offline AI-era convergence and value toolkit

Research only; no production/API/database changes, live SDK, uploads or source execution.

Process metadata, pair relationships and course policy are different objects. Different providers or identical code never automatically grant independent labels. Synthetic fixtures remain DEVELOPMENT_ONLY; FPR/F1/AP are not estimated from them. Historical experiments are not overwritten.

Entry points: `examples/make_seed.py` (13 hand-written fixtures), `protocol.py --schema-output`, `ingest.py`, `validate.py`, `build_pairs.py`, `analyze.py`, `jplag.py`, `prepare_review.py`, `export_public.py`, `report.py --run-dir` (inspect, no overwrite). All `--help` are local. Schemas follow executable Pydantic models, not an alternative production format; pairs bridge to the existing Research V4 loader.

Each snapshot/run needs a fresh output. Real code is restricted to ignored project/output; public exports are aggregate allowlists and still require human publication review. `--no-network` documents an invariant, never enables network. Syntax/functional failures and unknown relationships are retained; source relation and functional eligibility are separate.

Reports include read-only assignment preflight and submission review. Existing n-gram locations do not support an exhaustive match-length distribution. No AI-use attribution, misconduct probability, semantic-equivalence or teacher-efficiency conclusion.
